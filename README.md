# 🛒 Sistem Penjualan Produk – Kelompok 4

Aplikasi web sederhana untuk mengelola data produk toko, mulai dari melihat, menambah, mengedit, hingga menghapus produk.

## 🧰 Teknologi
- Vue.js 3
- Express.js
- MySQL
- Tailwind CSS
- Axios

## 📁 Struktur Folder
- `backend/` – Mengelola API.
- `frontend/` – Tampilan aplikasi.
- `database/` – Menyimpan file SQL.

## ⚙️ Cara Menjalankan

**1. Clone repository**
```bash
git clone https://github.com/irentaslim/proyek-pwd-kelompok.git
```

**2. Setup database**

Import `database/database_penjualan.sql` melalui phpMyAdmin.

**3. Jalankan backend**
```bash
cd backend
npm install
npm run dev
```

**4. Jalankan frontend** (terminal baru)
```bash
cd frontend
npm install
npm run dev
```

Buka alamat lokal yang muncul di terminal.
